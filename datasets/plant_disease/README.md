# Plant Disease Leaf Dataset Directory

```text
datasets/
└── plant_disease/
    ├── train/
    ├── validation/
    └── test/
```

## Instructions
1. Download the PlantVillage leaf image dataset (e.g. from Kaggle).
2. Place RGB leaf images into `train/`, `validation/`, and `test/` subdirectories corresponding to disease categories.
3. Keep dataset out of Git commits (referenced in `.gitignore`).
